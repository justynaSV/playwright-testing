# Playwright Testing Standards

Standards and conventions for writing Playwright tests, so all team members write them the same way.

> Status: scaffold only. Conventions and examples will be filled in incrementally.

## Contents
- `conventions.md` — naming, structure, locator strategy, assertions, waiting, test data, tagging (to be filled in)
- `examples/` — reference spec files demonstrating the conventions (to be added)
- `.github/copilot-instructions.md` — AI-facing summary of the conventions, so Copilot/AI tools follow this standard when generating Playwright tests

## Relation to other QA standards
This repo is one of the specialized standards repos referenced from the central QA AI hub:
- QA AI standards hub: https://github.com/justynaSV/qa-ai-standards
